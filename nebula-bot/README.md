# 🤖 NEBULA Bot — Telegram-бот-витрина услуг

Бот для студии **NEBULA**: каталог услуг с ценами по сложности,
калькулятор стоимости и приём заявок прямо в Telegram.

## Ассортимент

| Категория | Цены |
|---|---|
| 🌐 Сайты (лендинг, визитка, магазин, корпоративный) | **1 000 – 15 000 ₽** |
| 📱 Приложения (ПК, Android, iOS, веб, мессенджер, игра) | **5 000 – 25 000 ₽** |
| 🤖 Боты (простые, продвинутые, магазинные, Discord, парсеры) | 2 000 – 15 000 ₽ |
| 🎨 Дизайн (логотип, фирменный стиль, UI, соцсети) | 1 000 – 10 000 ₽ |
| 🚀 Продвижение и другое (поддержка, SEO, SMM, контент) | от 1 500 ₽ |

## Возможности

- 🏠 Главное меню с категориями
- 📋 Каталог: каждая услуга — с ценой и описанием
- 🧮 **Калькулятор стоимости**: тип → сложность → оценка в ₽
- 📝 **Заказ в один клик**: клиент описывает задачу → заявка уходит тебе в личку
- 💳 **Оплата предоплаты** через FreeKassa: клиент вводит сумму → ссылка на оплату → подтверждение тебе и клиенту
- ⚖️ **Документы**: пользовательское соглашение и политика конфиденциальности (Telegraph)
- ℹ️ Инфо о студии и контакты

## Установка (один раз)

1. Установи Python 3.10+ (https://python.org)
2. Создай бота у [@BotFather](https://t.me/BotFather) — команда `/newbot`, получи токен вида `123456:ABC-DEF...`
3. Скопируй настройки:

   ```bat
   copy .env.example .env
   ```

4. Открой `.env` и впиши:

   ```ini
   BOT_TOKEN=123456:ABC-DEF...        ← токен от BotFather
   OWNER_CHAT_ID=                      ← твой chat_id (спроси у @userinfobot) — сюда будут падать заявки
   CONTACT=@Kvezovs                   ← как с тобой связаться клиентам
   ```

5. Поставь зависимости (или запусти `setup.bat`):

   ```bat
   python -m pip install -r requirements.txt
   ```

## Запуск

```bat
run.bat
```

или вручную из папки `nebula-bot`:

```bash
python nebula_bot.py
```

Бот работает, пока скрипт запущен. Остановка — `Ctrl+C`.

## 💳 Онлайн-оплата (FreeKassa)

Приём оплат состоит из двух процессов:

1. **Бот** (`python nebula_bot.py`) — кнопка «💳 Оплатить»: клиент вводит сумму,
   бот создаёт заказ через `api.freekassa.ru` и присылает ссылку на оплату.
2. **Вебхук оплат** (`python pay_webhook.py`) — локальный HTTP-сервер на порту
   `FK_WEBHOOK_PORT` (8090). FreeKassa присылает сюда уведомления об оплате,
   сервер проверяет подпись и пишет подтверждение клиенту и владельцу.

### Настройка FreeKassa

В панели мерчанта (активация) укажи публичные адреса через SSH-туннель:

| Поле | Значение |
|---|---|
| URL оповещения (GET) | `https://<tunnel>.lhr.life/freekassa/notify` |
| URL успешной оплаты (GET) | `https://<tunnel>.lhr.life/freekassa/success` |
| URL возврата (GET) | `https://<tunnel>.lhr.life/freekassa/fail` |

Туннель запускается скриптом `..\pay-tunnel.ps1` (форвардит на порт 8090),
текущий адрес лежит в `..\pay-current-url.txt` и в `%TEMP%\opencode\pay-url.log`.

⚠️ Адрес `*.lhr.life` меняется при каждом переподключении туннеля — если он сменился,
обнови URL в панели FreeKassa.

В `.env` обязательно заполни:

```ini
FK_MERCHANT_ID=25965          ← твой числовой ID мерчанта
FK_SECRET1=...                ← секретное слово 1
FK_SECRET2=...                ← секретное слово 2
```

Проверка подписи уведомления:
`md5(MERCHANT_ID:AMOUNT:FK_SECRET{SIGN}:MERCHANT_ORDER_ID)`.

## Файлы

| Файл | Назначение |
|---|---|
| `nebula_bot.py` | сам бот (весь код в одном файле) |
| `freekassa.py` | сборка подписей и создание заказов FreeKassa |
| `pay_webhook.py` | вебхук-сервер оплат (приём уведомлений) |
| `../pay-tunnel.ps1` | SSH-туннель вебхука на публичный адрес |
| `.env.example` | шаблон настроек → скопируй в `.env` |
| `requirements.txt` | зависимости |
| `setup.bat` / `run.bat` | установка / запуск на Windows |

## Как поменять цены

Все товары лежат в начале `nebula_bot.py` в словарях `SERVICES_*` —
правь названия, цены и описания и перезапусти бота.
